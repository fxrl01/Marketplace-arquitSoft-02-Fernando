# Principios de diseño SOLID

- SRP: cada clase tiene una responsabilidad principal.
- OCP: nuevas implementaciones se agregan sin modificar reglas existentes.
- LSP: implementaciones pueden sustituir correctamente sus abstracciones.
- ISP: interfaces pequeñas y específicas.
- DIP: los casos de uso dependen de abstracciones y no de proveedores concretos.
