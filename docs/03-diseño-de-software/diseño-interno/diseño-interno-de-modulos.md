# Diseño interno de módulos

| Módulo | Responsabilidad |
|---|---|
| Usuarios | Gestión de usuarios y autenticación |
| Sellers | Gestión de vendedores |
| Catálogo | Productos, búsqueda y disponibilidad |
| Carrito | Productos seleccionados y cantidades |
| Pedidos | Creación y seguimiento de pedidos |
| Pagos | Procesamiento y estado de pagos |

Cada módulo mantiene sus responsabilidades y colabora mediante interfaces definidas.
