# Patrones de diseño

## Adapter
Utilizado para desacoplar pagos y envíos de sus proveedores externos.

## Facade
Permite coordinar operaciones complejas del proceso de compra mediante una interfaz simple.

## Factory
Permite crear implementaciones según el proveedor o tipo requerido.

## Circuit Breaker
Protege al sistema ante fallas continuas de servicios externos.
